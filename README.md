# Web Security Lab Write-ups

A hands-on web application security learning portfolio documenting my completed labs from PortSwigger Web Security Academy.

## About This Repository

This repository contains my personal lab notes, testing methodology, sanitized evidence, security impact analysis, and remediation guidance from authorized web security training environments.

The goal is to document practical learning and build a structured reference for web application security testing.

## Vulnerability Categories

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Server-Side Request Forgery (SSRF)
- Path Traversal
- Business Logic Vulnerabilities
- File Upload Vulnerabilities
- JWT Authentication
- API Security

## Tools & Technologies

- Burp Suite Community Edition
- Browser Developer Tools
- HTTP request and response analysis
- Markdown documentation

Tools listed here reflect my learning workflow where applicable.

## Write-up Format

Each documented lab may include:

- Lab objective and learning goals
- Testing methodology
- Sanitized screenshots or request/response evidence
- Root cause and potential security impact
- Recommended remediation
- Key learning outcomes

## Progress

This portfolio is being organized progressively. Only labs I have actually completed will be marked as solved. Work in progress will be identified separately.

## Responsible Testing

All practical testing documented here is conducted in authorized training environments or systems for which permission has been granted. Sensitive information is excluded from public evidence.
