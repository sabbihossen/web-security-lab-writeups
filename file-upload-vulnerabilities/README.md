# File Upload Vulnerabilities

## Overview

This repository section focuses on File Upload Vulnerabilities, a web security issue that occurs when an application fails to securely validate, store, or process uploaded files.

Improper file upload handling may allow attackers to upload malicious files, bypass extension restrictions, access sensitive information, or execute server-side code.

## Key Areas of Study

- Unrestricted File Upload
- File Extension Validation Bypass
- MIME Type and Content-Type Validation
- File Signature Validation
- Web Shell Upload Risks
- Server-Side Code Execution
- Apache `.htaccess` Misconfiguration
- Secure File Storage and Access Control
