# SQL Injection (SQLi)

## Overview

This directory documents my hands-on SQL Injection labs completed in PortSwigger Web Security Academy.

## Learning Objectives

- Understand how SQL injection vulnerabilities occur.
- Identify unsafe handling of user-controlled input in SQL queries.
- Practice authorized lab testing using browser tools and Burp Suite.
- Understand the potential impact of SQL injection.
- Learn secure query handling and remediation techniques.

## Lab Write-ups

Completed labs will be documented individually as I organize my notes and evidence.

Each write-up will include the lab title, objective, testing methodology, sanitized evidence, root cause, impact, and remediation.

## Status

Documentation in progress. Individual labs will be marked as solved only after verifying completion.
